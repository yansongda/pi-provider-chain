# 页脚文案：`→` / `↓` 区分档位，恢复时间取「链路内最早」

- 日期：2026-10-16
- 范围：页脚文案与取值来源（`MESSAGES.footerActive` / `MESSAGES.footerDegraded`、`src/ui.ts`、`src/router.ts#refreshStatus` / `earliestRecovery`）
- 不在范围内：状态文件 schema、档位推进、路由决策、notify 与转录条目文案

## 决策

| # | 决策 |
|---|---|
| 1 | 图标按「当前用的是链路第几个 provider」区分：档位 0 → `→`（U+2192）；档位 ≥ 1 → `↓`（U+2193）。两个字形同族（都是 BMP 细箭头），避免 `⬇`（U+2B07）在终端里被渲染成彩色 emoji、与 `→` 粗细不一致 |
| 1b | 页脚不再使用 `⚠`（`⚠` 保留在 notify 与转录条目——那里是「事件」语义） |
| 2 | 去掉旧文案里的「备用」二字（它容易被读成「这就是备用模型」，而非「这是降级后的当前模型」） |
| 3 | 恢复时间改成 `· <MM-DD HH:mm> 恢复 <provider>`：时间取**当前选中模型链路内仍活跃的降级条目里 `until` 最小者**（并列取链路靠前者），`provider` 即该条目所属 provider |

示例（volcengine level=1，窗口至 `10-28 23:59`）：`↓ workbuddy/deepseek-v4.1-flash · 10-28 23:59 恢复 volcengine`

## 理由

- 旧文案 `⚠ 备用 workbuddy/… · 恢复 10-28 23:59` 没有说明「这是谁的时间」，读者容易误读为「workbuddy 在 23:59 之前不可用」。
- 图标选型：`→` / `↓` 同族细箭头；不用 `⬇`（U+2B07，多为 emoji 呈现，宽度与颜色不可控），也不用 `->`（ASCII 双字符，撑宽页脚）。
- `stateKey = chain[0].provider`，链路其它成员只有在「它也是别的虚拟模型的 `chain[0]`」时才会有条目；页脚要回答的是「链路上谁先恢复」，因此按链路范围取最早，而不是只看本模型的档位。

## 影响

- 已知边界：页脚显示的「最早恢复」**不保证**是「回到主用」的时间——回到主用始终取决于本模型 `stateKey`（即 `chain[0]`）的窗口。当前配置（所有模型 `chain[0] = volcengine`）下两者恒等。
- 纯文案 + 取值来源改动：档位推进、保缓存路径、状态文件 `version: 1` 契约、旧会话转录条目渲染均不受影响。

## 失效条件

- 若状态文件改为「按 provider 记录链路每个成员的窗口」，「取最早」可能变成误导，需改回「只显示本模型 `chain[0]` 的窗口」或按新语义重算。
- 若页脚需要保留警示等级（`⚠`，或 `↓↓` 这样的深度标记），只需改 `MESSAGES.footerActive` / `MESSAGES.footerDegraded` 两个模板与对应断言。
